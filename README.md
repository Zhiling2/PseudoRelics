1. Introduction
Several tools have been developed to perform pseudogene prediction and annotation in plant and animal genomes. Most existing tools focus on intergenic region pseudogenes, typically masking the genic regions.
PseudoRelics is a Python-based pseudogene prediction and annotation tool that identifies pseudogenes from both intergenic and genic regions. It outputs the location, sequence characteristics, and annotation information of pseudogenes through:
 sequence alignment (via Exonerate),
 mass filtering,
 redundancy removal,
 and other steps.
This makes it suitable for  pseudogene function in both plant and animal genomes.

3. Usage
Input
PseudoRelics requires four input files (strictly formatted):
1.Genome FASTA (genome.fa)
oIDs must match the seqid in the GFF (e.g., >Chr1 ↔ seqid=Chr1).
oUse standard FASTA format (no unusual characters).

>Chr1
AGCTTTTCATTCTGACTGCAACGGGCAATATGTCTCTGTGTGGATTAAAAAAAGAGT...

2.Protein FASTA (pep.fa)
oIDs must match qseqid in the alignment table.
oStandard amino acid codes only (A–Z).

>AT1G01010.1
MAKELQKQIEELQSKYKDVHPNIVGFLGGTGSGKSTLVQRLAKELGLNVTVSQYVST...

3.Gene Annotation GFF (gene.gff)
oMust comply with GFF3 standard.
oMust contain ID field in the attributes column.
Example: 
Chr1   Araport11   gene   105000   106500   .   +   .   ID=AT1G01010;Name=ABC1

4.Alignment Table (m6 format)
Generated by tBLASTn or MMseqs2. Must be 12-column tabular format (outfmt 6).
Example command (BLASTp):
makeblastdb -in genome.fa -dbtype nucl -out genome_db -parse_seqids
tblastn -query proteins.fa -db genome_db -outfmt 6 -out blastp_m6.txt -num_threads 12


Running PseudoRelics
i.Command-line (recommended)
Create a script run_pseudo_relics.py like this
#!/usr/bin/env python3

import argparse
from ..wkfls import wkfl_pseudo_relics  # Core class

def main():
    # 1. Parse command-line arguments
    parser = argparse.ArgumentParser(description="PseudoRelics: Pseudogene Annotation Tool")

    # Parallelization
    parser.add_argument("--proc_num", type=int, default=1,
                        help="Number of processes (default: 1)")

    # Pipeline mode
    parser.add_argument("--ppl_mode", type=str, default="IGR", choices=["IGR", "GR"],
                        help="Pipeline mode: IGR (intergenic) or GR (genic)")

    # Input files
    parser.add_argument("--align_tab", required=True,
                        help="Alignment table file (BLAST .m6 or Exonerate sugar format)")
    parser.add_argument("--gff", required=True, help="Annotation file (GFF3 recommended)")
    parser.add_argument("--geno_fa", required=True, help="Genome FASTA file")
    parser.add_argument("--pep_fa", required=True, help="Protein FASTA file (ancestral genes)")

    # Outputs
    parser.add_argument("--output_dir", required=True, help="Directory for outputs")
    parser.add_argument("--output_gff", action="store_true", help="Export GFF output")
    parser.add_argument("--output_bed", action="store_true", help="Export BED output")
    parser.add_argument("--output_fa", action="store_true", help="Export FASTA (raw/CDS/pep)")

    # Compare tool config
    parser.add_argument("--exone_prog", help="Path to exonerate binary")
    parser.add_argument("--exone_wdir", help="Temporary directory for exonerate")

    # Quality thresholds
    parser.add_argument("--idt_thold", type=int, default=60,
                        help="Identity threshold % (default: 60)")
    parser.add_argument("--cov_thold", type=int, default=40,
                        help="Coverage threshold % (default: 40)")

    args = parser.parse_args()

    # 2. Initialize and run workflow
    pipeline = wkfl_pseudo_relics.workflow_pseudo_relics(
        proc_num_i=args.proc_num,
        ppl_mode_i=args.ppl_mode,
        align_tab_file_i=args.align_tab,
        gff_tab_file_i=args.gff,
        geno_fa_file_i=args.geno_fa,
        pep_fa_file_i=args.pep_fa,
        output_dir_i=args.output_dir,
        output_gff_i=args.output_gff,
        output_bed_i=args.output_bed,
        output_raw_fa_i=args.output_fa,
        output_cds_fa_i=args.output_fa,
        output_pep_fa_i=args.output_fa,
        exone_prog_i=args.exone_prog,
        exone_wdir_i=args.exone_wdir,
        idt_thold_i=args.idt_thold,
        cov_thold_i=args.cov_thold
    )
    pipeline.perform_flow()  # Start pseudogene annotation

if __name__ == "__main__":
    main()

Output
Key outputs include:
 briefing.tsv → core pseudogene info (ID, type, coverage, introns, mutations, etc.)
 detail.align → alignment visualization between pseudogene and ancestral gene
 briefing.gff → pseudogene annotation (GFF3 format)
 briefing.bed → pseudogene coordinates (BED format)
 pseudo_raw.fa, pseudo_cds.fa, pseudo_pep.fa → pseudogene sequences

Test
A test dataset is provided for validation of installation and workflow execution.
